# 📝 How to Use Profile & Settings - User Guide

## ✅ Your Data WILL Persist!

LearnSphere Pro automatically saves all your profile and settings data to a database. Your information will be there every time you log in!

---

## Step-by-Step Guide

### 1. Update Your Profile

1. **Login** to LearnSphere Pro
2. **Navigate** to Profile page (from sidebar)
3. **Fill in your information**:
   - Full Name
   - Bio
   - Learning Interests
   - Experience Level
   - Location
   - Occupation
   - Website

4. **Click** "💾 Save Profile"
5. **See** success message: "✅ Profile saved successfully!"

### 2. Update Your Settings

1. **Navigate** to Settings page (from sidebar)
2. **Choose your preferences**:
   - Theme (Dark/Light/Auto)
   - Language
   - Default Difficulty
   - Notifications

3. **Click** "💾 Save Settings"
4. **See** success message: "✅ Settings saved successfully!"

### 3. Verify Data Persists

1. **Logout** (click "🚪 Logout" in sidebar)
2. **Login** again with same credentials
3. **Go to Profile page**
   - ✅ All your profile data is still there!
4. **Go to Settings page**
   - ✅ All your settings are still saved!

## Troubleshooting

### "I don't see my data after login"

**Solution**: Navigate to the Profile or Settings page. The data loads when you open those pages.

### "Save button doesn't show success message"

**Solution**: 
1. Check your internet connection
2. Make sure you filled in required fields
3. Try clicking Save again

### "My data disappeared"

**Solution**: 
1. Make sure you're logged in with the correct account
2. Check if you clicked the Save button
3. Verify you saw the success message

---

## Best Practices

1. **Always click Save** after making changes
2. **Wait for success message** before navigating away
3. **Use Logout button** instead of just closing browser
