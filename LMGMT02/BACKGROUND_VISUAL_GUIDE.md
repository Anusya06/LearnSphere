### 1. Full-Screen Background
- **Coverage**: Entire viewport from edge to edge

- **Color**: Black with 70% opacity

## 🎯 Best Practices

### Image Selection
1. **Resolution**: 1920x1080 minimum
2. **Format**: PNG for transparency, JPG for photos
3. **Size**: < 500KB (compress if needed)
4. **Theme**: Match your brand colors
5. **Contrast**: Ensure text readability

### Overlay Adjustment
- **Light images**: Use darker overlay (0.8)
- **Dark images**: Use lighter overlay (0.5-0.6)
- **Busy images**: Use stronger blur
- **Simple images**: Use less blur

### Testing
1. Test on multiple screen sizes
2. Check text readability
3. Verify scroll behavior
4. Test in different browsers
5. Check performance metrics
