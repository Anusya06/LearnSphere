## 🚀 Quick Setup (5 Minutes)

### Step 1: Get API Key
1. **Go to:** https://console.groq.com
2. **Sign up** (free, no credit card required)
3. **Click:** "API Keys" in sidebar
4. **Click:** "Create API Key"
5. **Copy** the key (starts with `gsk_`)

### Step 2: Update Secrets File
Open: `frontend/.streamlit/secrets.toml`

Replace this line:
```toml
GROQ_API_KEY = "gsk_YOUR_API_KEY_HERE"
```

With your new key:
```toml
GROQ_API_KEY = "gsk_YOUR_NEW_KEY_HERE"
```

### Step 3: Restart App
The app will automatically reload and connect to Groq!

## 🆘 Troubleshooting

### Error: "Invalid API Key"
- **Solution:** Get new key from https://console.groq.com
- **Check:** Key starts with `gsk_`
- **Verify:** No extra spaces in secrets.toml

### Error: "API key not found"
- **Solution:** Check file path: `frontend/.streamlit/secrets.toml`
- **Verify:** File exists in correct location
- **Restart:** App after creating file

### Error: "Model decommissioned"
