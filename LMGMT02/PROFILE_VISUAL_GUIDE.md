## Color Coding

### Achievement States
- **Unlocked** (Green border, full opacity)
  - Border: #10b981
  - Opacity: 1.0
  - Status: "Unlocked!"

- **Locked** (Gray border, reduced opacity)
  - Border: #d1d5db
  - Opacity: 0.4
  - Status: "Locked"

### Quiz Scores
- **High Score** (≥70%): Green (#10b981)
- **Low Score** (<70%): Orange (#f59e0b)

### Stat Cards
- Topics: Purple (#667eea)
- Quizzes: Purple (#764ba2)
- Score: Green (#10b981)
- Tasks: Orange (#f59e0b)

## Responsive Layout

### Desktop (Wide Screen)
- Sidebar: 1/3 width
- Main content: 2/3 width
- 2-column achievement grid
- 4-column statistics grid

### Mobile (Narrow Screen)
- Sidebar: Full width (stacked)
- Main content: Full width (below)
- 1-column achievement grid
- 2-column statistics grid
