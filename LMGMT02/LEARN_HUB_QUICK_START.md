## 🚀 How to Use (3 Steps)

### Step 1: Access the Learn Hub
```
1. Open: http://localhost:8502
2. Login to your account
3. Click "📚 Learn" in the sidebar
```

### Step 2: Generate Content
```
1. Enter a topic (e.g., "Neural Networks")
2. Select difficulty (Beginner/Intermediate/Advanced)
3. Click "🚀 Generate"
4. Wait 3-5 seconds for AI to create content
```

### Step 3: Explore All Tabs
```
📖 Content   - Read the lesson
🔊 Audio     - Listen to narration
🤖 Tutor     - Ask questions
🎥 Videos    - Watch tutorials
💻 Code      - See examples
🗺️ Roadmap   - Track progress
```

## ❓ Troubleshooting

### Audio Not Working?
```bash
pip install gtts
```
Then restart the app.

### Content Not Generating?
- Check Groq API key in secrets.toml
- Verify internet connection
- Try a different topic

### Progress Not Saving?
- Ensure you're logged in
- Check database file exists
- Verify user_id in session

### Code Not Running?
- Only Python runs locally
- Other languages show code only
- Check code_executor.py for details
