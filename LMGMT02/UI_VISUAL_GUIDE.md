## 🎨 Color Scheme

### Primary Colors
- **Purple**: `#667eea` - Main brand color
- **Violet**: `#764ba2` - Secondary brand color
- **Green**: `#10b981` - Success/AI responses

### Backgrounds
- **Dark**: `rgba(30, 30, 30, 0.7)` - Glass cards
- **Darker**: `rgba(30, 30, 30, 0.5)` - Content cards

### Text
- **Primary**: `#fafafa` - Main text
- **Secondary**: `#b0b0b0` - Captions
- **Muted**: `#666` - Footer

## ✨ Interactive Elements

### Hover Effects
- **Stat Cards**: Lift up 5px
- **Feature Cards**: Lift up 5px
- **Buttons**: Lift up 2px + shadow
- **Flashcards**: Scale up 2%

### Animations
- **Transitions**: 0.3s ease
- **Smooth**: All hover effects
- **Professional**: Subtle movements

## 📱 Layout

### Wide Mode
- Full screen width
- Expanded sidebar
- Maximum content area
- Professional spacing

### Grid System
- 3-column stats
- Responsive feature grid
- Flexible layouts
- Mobile-friendly

## 🎯 Typography

### Headers
- **Hero**: 3rem, weight 800
- **Section**: 1.8rem, weight 700
- **Subtitle**: 1.3rem

### Body
- **Content**: 1rem, line-height 1.8
- **Captions**: 0.9rem
- **Footer**: 0.8-0.9rem
