## Troubleshooting

### If Tests Don't Pass
1. Check you're using Python (not JavaScript/Java/C++)
2. Verify code has no syntax errors
3. Make sure function name matches challenge
4. Check test cases are properly formatted

### If Language Indicator Missing
1. Refresh the page
2. Generate a new challenge
3. Check browser console for errors

### If Button Disabled
- This is correct for non-Python languages!
- Switch to Python to enable testing
