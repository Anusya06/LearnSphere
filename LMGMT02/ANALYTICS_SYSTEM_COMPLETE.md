## 🗄️ Database Schema

### New Tables Created:

#### 1. learning_topics
Stores all generated learning topics
```sql
CREATE TABLE learning_topics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    topic_name TEXT NOT NULL,
    difficulty TEXT,
    generated_content TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
)
```

**Purpose**: Track every topic a user generates on the Learn page

**Example Data**:
```
user_id: 12
topic_name: "Deep Learning"
difficulty: "Intermediate"
generated_content: "AI generated explanation..."
created_at: "2024-06-01 14:30:00"
```

---

#### 2. quiz_results
Stores all quiz attempts and scores
```sql
CREATE TABLE quiz_results (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    topic TEXT NOT NULL,
    score INTEGER NOT NULL,
    total_questions INTEGER NOT NULL,
    percentage REAL,
    time_taken INTEGER,
    attempted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
)
```

**Purpose**: Track quiz performance over time

**Example Data**:
```
user_id: 12
topic: "Deep Learning"
score: 7
total_questions: 10
percentage: 70.0
time_taken: 120
attempted_at: "2024-06-02 10:15:00"
```

## 🛠️ Database Methods

### Analytics Methods:

#### `save_learning_topic(user_id, topic_name, difficulty, content)`
- Saves generated topic to database
- Called from Learn page after content generation
- Returns: `bool` (success/failure)

#### `save_quiz_result(user_id, topic, score, total_questions, time_taken)`
- Saves quiz attempt to database
- Calculates percentage automatically
- Called from Quiz page after submission
- Returns: `bool` (success/failure)

#### `get_learning_topics(user_id, limit=50)`
- Retrieves all topics for user
- Sorted by created_at DESC
- Returns: `List[Dict]` with topic_name, difficulty, created_at

#### `get_quiz_results(user_id, limit=50)`
- Retrieves all quiz attempts for user
- Sorted by attempted_at DESC
- Returns: `List[Dict]` with topic, score, total_questions, percentage, time_taken, attempted_at

#### `get_analytics_summary(user_id)`
- Calculates summary statistics
- Returns: `Dict` with:
  - topics_learned: int
  - quizzes_attempted: int
  - average_score: float
  - latest_topic: str

#### `get_quiz_performance_trend(user_id, limit=15)`
- Gets quiz scores for trend chart
- Sorted by attempted_at ASC (chronological)
- Returns: `List[Dict]` with topic, percentage, attempted_at

#### `get_recent_activity(user_id, limit=10)`
- Combines topics and quizzes
- Sorted by timestamp DESC
- Returns: `List[Dict]` with type, description, timestamp

## 📊 Sample Queries

### Get User's Learning Summary:
```sql
SELECT 
    (SELECT COUNT(*) FROM learning_topics WHERE user_id = ?) as topics,
    (SELECT COUNT(*) FROM quiz_results WHERE user_id = ?) as quizzes,
    (SELECT AVG(percentage) FROM quiz_results WHERE user_id = ?) as avg_score
```

### Get Recent Topics:
```sql
SELECT topic_name, difficulty, created_at
FROM learning_topics
WHERE user_id = ?
ORDER BY created_at DESC
LIMIT 10
```

### Get Quiz Performance:
```sql
SELECT topic, score, total_questions, percentage, attempted_at
FROM quiz_results
WHERE user_id = ?
ORDER BY attempted_at DESC
LIMIT 10
```

### Get Activity Timeline:
```sql
SELECT 'topic' as type, topic_name as name, created_at as timestamp
FROM learning_topics
WHERE user_id = ?
UNION ALL
SELECT 'quiz' as type, topic as name, attempted_at as timestamp
FROM quiz_results
WHERE user_id = ?
ORDER BY timestamp DESC
LIMIT 20
```
